# دليل ملفات مشروع SHM_dashboard

شرح لكل ملف في المشروع (الموقع الإلكتروني + لوحة الإدارة).

---

## 📁 الملفات في جذر المشروع (Root)

### `package.json`
- **الوظيفة:** تعريف المشروع وحزم npm.
- **يحتوي على:** اسم المشروع (`shm_dashboard`)، السكربتات (`dev`, `build`, `lint`, `preview`)، والمكتبات (React, React Router, React Icons, Vite, Tailwind).
- **مهم:** عند النشر على Vercel يُستخدم `npm run build` لبناء المشروع و`dist` كمجلد المخرجات.

### `package-lock.json`
- **الوظيفة:** تثبيت نسخ محددة من كل الحزم لضمان نفس البيئة عند التثبيت على أي جهاز.

### `index.html`
- **الوظيفة:** نقطة دخول التطبيق في المتصفح.
- **يحتوي على:** عنوان الصفحة "سهم — ورشة سيارات متنقلة"، و`<div id="root">` الذي يُحمّل فيه React، وربط سكربت `/src/main.jsx`.
- **ملاحظة:** `lang="ar"` و`dir="rtl"` لدعم العربية.

### `vite.config.js`
- **الوظيفة:** إعدادات أداة Vite (بناء وتشغيل التطبيق).
- **يحتوي على:** إضافة React، منفذ التطوير 5173، مجلد البناء `dist`، وتعطيل فتح المتصفح تلقائياً.

### `tailwind.config.js`
- **الوظيفة:** إعدادات Tailwind CSS.
- **يحتوي على:** مسح الملفات (`index.html`, `src/**/*.{js,jsx,ts,tsx}`) لتوليد الـ CSS، وإضافة أنيميشن مثل `fadeIn`.

### `postcss.config.js`
- **الوظيفة:** إعدادات PostCSS لمعالجة CSS.
- **يحتوي على:** إضافة `@tailwindcss/postcss` لدمج Tailwind مع المشروع.

### `eslint.config.js`
- **الوظيفة:** قواعد ESLint لفحص جودة الكود.
- **يحتوي على:** دعم JS/JSX، قواعد React Hooks و React Refresh، وتجاهل مجلد `dist`.

### `vercel.json`
- **الوظيفة:** إعدادات النشر على Vercel.
- **يحتوي على:** قاعدة `rewrites` لإرسال كل المسارات إلى `index.html` حتى يعمل React Router (الصفحة الرئيسية، السياسات، `/dashboard`) بدون أخطاء 404.

### `README.md`
- **الوظيفة:** وصف عام للمشروع وتعليمات التشغيل (إن وُجدت).

### `VERCEL_DEPLOY.md`
- **الوظيفة:** دليل خطوة بخطوة لرفع المشروع على Vercel (الموقع + Dashboard).

## 📁 مجلد `src/` — الكود الرئيسي

### نقطة الدخول والتطبيق

#### `main.jsx`
- **الوظيفة:** نقطة تشغيل التطبيق في المتصفح.
- **يقوم بـ:** استيراد `index.css` و`App.jsx`، وعرض `<App />` داخل `<div id="root">` باستخدام React 18.
- **ملاحظة:** يوجد معالجة أخطاء (try/catch) وعرض رسالة عربية عند فشل التحميل.

#### `App.jsx`
- **الوظيفة:** تعريف المسارات (Routing) والتخطيط العام.
- **يحتوي على:**
  - **صفحات عامة** داخل `PublicLayout`: الرئيسية `/`، الخصوصية `/privacy`، الشروط `/terms`، الاسترجاع `/returns`.
  - **لوحة الإدارة** `/dashboard` محمية بـ `DashboardGate` (تسجيل دخول).
  - إعادة توجيه `/login` إلى `/dashboard`.
  - أي مسار غير معرّف يُحوّل إلى الرئيسية `/`.
- **حالة (State):** `loggedIn` لتحديد عرض شاشة الدخول أو لوحة التحكم.

---

### الموقع العام (Public Site)

#### `PublicLayout.jsx`
- **الوظيفة:** الهيكل المشترك لجميع الصفحات العامة (الهيدر + المحتوى + التذييل).
- **يحتوي على:** هيدر ثابت (لوجو سهم، روابط: الرئيسية، خدماتنا، السياسات، أزرار دخول الإدارة وحمل التطبيق)، و`<main>` يعرض الصفحة الحالية عبر `<Outlet />`، ثم `<Footer />`.
- **ملاحظة:** الصفحة بالكامل `dir="rtl"` للعربية.

#### `Home.jsx`
- **الوظيفة:** الصفحة الرئيسية للموقع.
- **يحتوي على:** قسم الهيرو (هاتف وهمي + عنوان + أزرار تحميل التطبيق)، قسم مميزاتنا (أربع ميزات بأيقونات)، فواصل بيضاء، قسم كيف يعمل (ثلاث خطوات)، قسم السياسات والوثائق (ثلاث روابط).
- **بيانات:** مصفوفات `benefits` و`howItWorks` للنصوص والعناوين.

#### `Footer.jsx`
- **الوظيفة:** تذييل الصفحة في الموقع العام.
- **يحتوي على:** أعمدة (اتصل بنا، مساعدة، الشركة، اللوجو + أزرار التطبيق)، روابط السوشيال، حقوق النشر، وبيانات الشركة (س.ج، ضريبة، عنوان).
- **ملاحظة:** بيانات التذييل مخزنة في كائن `FOOTER` في أعلى الملف ويمكن تعديلها من هناك.

#### `Privacy.jsx`
- **الوظيفة:** صفحة سياسة الخصوصية.
- **يحتوي على:** عنوان، فقرات، وأقسام (ما البيانات التي نجمعها، لماذا نستخدمها، إلخ) داخل حاوية منسقة.

#### `Terms.jsx`
- **الوظيفة:** صفحة الشروط والأحكام.
- **يحتوي على:** مصفوفة `sections` (عنوان + نص) تعرض كأقسام مرقمة (قبول الشروط، التعريفات، الأهلية، طلب الخدمة، الأسعار، الإلغاء، إلخ).

#### `Returns.jsx`
- **الوظيفة:** صفحة سياسة الاسترجاع.
- **يحتوي على:** مصفوفة `sections` (نطاق السياسة، حالات الاسترجاع، آلية الطلب، مدة المعالجة، إلخ) مع عرض منسق.

### لوحة الإدارة (Dashboard)

#### `DashboardGate.jsx`
- **الوظيفة:** بوابة الدخول — يقرر عرض شاشة تسجيل الدخول أو لوحة التحكم.
- **المنطق:** إذا `loggedIn === false` يعرض `<Login onLogin={...} />`، وإلا يعرض `<Dashboard onLogout={...} />`.
- **يتعامل مع:** التوجيه بعد تسجيل الدخول إلى `/dashboard` وبعد تسجيل الخروج إلى `/`.

#### `Login.jsx`
- **الوظيفة:** شاشة تسجيل الدخول للوحة الإدارة.
- **يحتوي على:** حقول اسم المستخدم وكلمة المرور، زر الدخول، رسالة خطأ، وتصميم بخلفية متدرجة ونمط هندسي.
- **ملاحظة:** الدخول حالياً محلي (مثلاً admin / shm123) بدون اتصال بـ API حقيقي؛ يمكن ربطه لاحقاً بـ Backend.

#### `Dashboard.jsx`
- **الوظيفة:** الهيكل الداخلي للوحة التحكم بعد تسجيل الدخول.
- **يحتوي على:** `Sidebar` (قائمة: الطلبات، الفنيين، الإعدادات)، ومنطقة محتوى تعرض إما `Orders` أو `Technicians` أو صفحة الإعدادات أو `OrderDetails` عند فتح طلب.
- **حالة:** `page` (الصفحة الحالية)، `selectedOrder` (الطلب المفتوح)، و`refreshOrdersRef` لتحديث قائمة الطلبات بعد التعديل.

#### `Sidebar.jsx`
- **الوظيفة:** الشريط الجانبي في لوحة الإدارة.
- **يحتوي على:** لوجو سهم، زر طي/فتح القائمة، عناصر القائمة (الطلبات، الفنيين، الإعدادات)، وزر تسجيل الخروج.
- **ملاحظة:** التصميم بتدرج أزرق ويدعم RTL.

#### `Orders.jsx`
- **الوظيفة:** صفحة قائمة طلبات الخدمة في لوحة الإدارة.
- **يحتوي على:** جلب الطلبات من الـ API (`GET /requests`)، فلترة حسب الحالة، عرض الطلبات في جدول/قائمة، أزرار تحديث وحذف، وفتح تفاصيل الطلب.
- **يعتمد على:** `config.js` (API_URL)، `servicePrices.js` لعرض السعر.

#### `OrderDetails.jsx`
- **الوظيفة:** صفحة تفاصيل طلب واحد.
- **يحتوي على:** عرض بيانات الطلب (العميل، الموقع، الخدمة، الحالة، إلخ)، تعيين فني للطلب، تحديث الحالة، وحذف الطلب.
- **يعتمد على:** `API_URL` و`getOrderPriceText` من `servicePrices.js`.

#### `Technicians.jsx`
- **الوظيفة:** صفحة إدارة الفنيين.
- **يحتوي على:** جلب الفنيين من الـ API، إضافة فني جديد، عرض التقييمات، وحذف فني.
- **يعتمد على:** `API_URL` من `config.js`.

### الإعدادات والبيانات المشتركة

#### `config.js`
- **الوظيفة:** إعدادات الاتصال بالـ Backend.
- **يحتوي على:** `API_URL` — يُؤخذ من متغير البيئة `VITE_API_URL` أو القيمة الافتراضية (مثل Railway: `https://shmapp-production.up.railway.app`).
- **ملاحظة:** في Vercel يمكن تعيين `VITE_API_URL` في Environment Variables.

#### `servicePrices.js`
- **الوظيفة:** تسعيرات الخدمات (متزامن مع تطبيق Flutter).
- **يحتوي على:** كائن `servicePrices` (نوع الخدمة → سعر وكونه متغيراً أم لا)، ودوال مساعدة مثل `getServicePrice` و`isServicePriceVariable` و`getOrderPriceText` لعرض السعر في لوحة الإدارة.

### الأنماط (CSS)

#### `index.css`
- **الوظيفة:** الأنماط العامة للتطبيق.
- **يحتوي على:** استيراد Tailwind، إعادة تعيين بسيطة (`*`, `body`)، وخط النظام و`#root { min-height: 100vh }`.

#### `App.css`
- **الوظيفة:** أنماط إضافية من قالب Vite (مثل `.logo`, `.card`).
- **ملاحظة:** قد لا يُستورد في التطبيق الحالي؛ التصميم يعتمد أساساً على Tailwind و`index.css`.

## 📁 مجلد `public/`

- **الوظيفة:** ملفات ثابتة تُنسخ كما هي إلى جذر الموقع عند البناء.
- **مثال:** `app-screenshot.png` — لقطة شاشة التطبيق تُعرض داخل الهاتف الوهمي في الصفحة الرئيسية.
- **ملاحظة:** أي ملف يوضع هنا يُشار إليه بـ `/اسم_الملف` (مثل `/app-screenshot.png`).

---

## 📁 مجلدات لا تُعدّل يدوياً

- **`node_modules/`** — الحزم المثبتة عبر `npm install`؛ لا يُرفع على Git ولا يُشرح لأنه تبعيات جاهزة.
- **`dist/`** — مخرجات أمر `npm run build`؛ يُنشأ عند البناء ويُستخدم عند النشر على Vercel.

| المسار أو القسم        | الملف الرئيسي      |
|------------------------|-------------------|
| `/`                    | `Home.jsx`        |
| `/privacy`             | `Privacy.jsx`     |
| `/terms`               | `Terms.jsx`       |
| `/returns`             | `Returns.jsx`     |

| التوجيه والمسارات      | `App.jsx`         |
| نقطة التشغيل           | `main.jsx`, `index.html` |
| إعدادات API والتسعير   | `config.js`, `servicePrices.js` |
